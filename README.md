#  Space Station 15

**Инди-ремейк легендарной атмосферной станции**  
Собственный движок на C# + Raylib • Реалистичная симуляция газов • Модульная архитектура как в оригинале

![SS15 Screenshot](https://via.placeholder.com/800x450.png?text=SS15+Pre-Alpha+Screenshot)

---

##  Что уже работает
- **Живая атмосфера** —  система **LINDA** (диффузия, давление, температура, теплообмен)
- **Предметы и инвентарь** — подбирайте, перекладывайте, используйте мышкой и клавишами
- **Классический UI** — руки, карманы, переключение активной руки (как в SS13)
- **Чат** — с поддержкой русского языка и шрифтов TrueType
- **Туман войны** — реалистичный обзор с рейкастингом
- **Настройки** — зум, лимит FPS, полноэкранный режим
- **Генерация карт** — 10×10, 100×100, 256×256 тайлов
- **Мониторинг производительности** — отрисовка, атмос-тик, обзор в мс

##  Управление
| Клавиша        | Действие                              |
|----------------|---------------------------------------|
| **WASD**       | Передвижение                          |
| **ЛКМ**        | Поднять предмет (по клику на него)    |
| **ЛКМ по UI**  | Взаимодействие с руками/карманами     |
| **Z**          | Использовать предмет в активной руке  |
| **X**          | Сменить активную руку                 |
| **Q**          | Выбросить предмет из активной руки    |
| **Tab / Колесо** | Переключить слот инвентаря         |
| **T**          | Открыть чат                           |
| **Esc**        | Меню (Game / Settings)                |
| **O/P/K/L/N/M/V** | Изменить газы/температуру в тайле под мышью |
| **R**          | Пересоздать карту                     |
| **F**          | Вкл/Выкл туман войны                  |
| **F11**        | Полноэкранный режим                   |
| **PageUp/Down**| Зум                                   |

##  Roadmap

- [ ] **Жизнеобеспечение и медицина** – здоровье, запас кислорода, урон от вакуума/токсинов, лечение  
- [ ] **Электричество и энергосеть** – генераторы, провода, освещение, обесточивание отсеков  
- [ ] **Строительство и крафт** – возведение стен, дверей, шлюзов; изготовление предметов  
- [ ] **Мультиплеер** – клиент-сервер на LiteNetLib, совместная игра, общий чат  
- [ ] **Генерация карт** – отсеки, комнаты, атмосферные трубы (загружаемые шаблоны)  
- [ ] **Звуки и анимации** – шаги, инструменты, фоновый эмбиент, анимированные двери  
- [ ] **Роли** – инженер, врач, уборщик, капитан (стартовый инвентарь и обязанности)  
- [ ] **Моддинг** – загрузка текстур, конфигов (JSON) и Lua-скриптов  
- [ ] **Оптимизация** – Ускорение загрузки билда и оптимизация  
- [ ] **Сюжетные ивенты** – случайные происшествия на станции (пожары, метеориты)
